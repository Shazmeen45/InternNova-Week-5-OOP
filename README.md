# InternNova – Week 5: Object-Oriented Programming (OOP)

This repository contains my Week 5 internship assignment for InternNova. The main topic of this week was Object-Oriented Programming (OOP) in Python.

Through these tasks, I practiced creating classes and objects, initializing attributes using constructors, implementing inheritance, using polymorphism, and applying abstraction and encapsulation.

## Tasks Completed

### Task 1 – Classes and Objects
- Created a `Student` class.
- Created two student objects.
- Displayed student information using a method.

### Task 2 – Constructor (`__init__`)
- Used a constructor to initialize object attributes.
- Created student objects with different values.
- Accessed attributes and displayed student details.

### Task 3 – Inheritance
- Created a parent class named `Person`.
- Created a child class named `Student`.
- Used `super()` to initialize inherited attributes.
- Displayed student information and course details.

### Task 4 – Polymorphism
- Created `Dog` and `Cat` classes.
- Implemented the same `sound()` method in both classes.
- Demonstrated how different objects respond differently to the same method call.

### Task 5 – Abstraction and Encapsulation
- Created an abstract `BankAccount` class.
- Used the `ABC` module and `@abstractmethod` decorator.
- Created a `SavingsAccount` child class.
- Implemented deposit and withdrawal operations.
- Used a private balance attribute and methods to access and update it.
- Checked for invalid amounts and insufficient balance.

## How to Run the Programs

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in Visual Studio Code.
4. Open a terminal in the project folder.
5. Run any task using the following command:

```bash
python task01.py
```

Replace `task01.py` with `task02.py`, `task03.py`, `task04.py`, or `task05.py` to run another task.
